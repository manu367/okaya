What is JavaScript?

JavaScript sirf ek programming language nahi hai.
Ye web ka nervous system hai.
HTML body hai, CSS skin hai — JavaScript dimaag hai.

Agar JavaScript hata do, to modern websites bas ek printed newspaper ban jaati hain — dikhti hain, par react nahi karti.

1. JavaScript kya hai?

JavaScript ek high-level, interpreted, dynamically typed programming language hai jo originally browsers ke liye banayi gayi thi — taaki web pages interactive ban sakein.

  • User actions ka jawab deta hai
  • Click, scroll, type, submit — sab jagah active

2. Short History

  • 1995 — Brendan Eich ne 10 din me banayi
  • Pehle naam: Mocha → LiveScript
  • Marketing ke chakkar me JavaScript (Java se direct relation nahi)
  • Pehle toy language, aaj backbone of web

3. JavaScript karta kya kya hai?

4. JavaScript Execution Model

JavaScript single-threaded hoti hai, par async behavior handle karti hai using:

  • Call Stack
  • Web APIs
  • Callback Queue
  • Event Loop (heartbeat)

5. Core Concepts

Variables

var (dangerous), let (safe), const (preferred)

Data Types

Primitive & Non-Primitive

Functions & Closures

Normal, Arrow, Higher-order, Closures (🔥)

6. JavaScript & OOP

JavaScript prototype-based language hai. class syntax sirf sugar hai — andar prototype hi chalta hai.

7. Modern JavaScript (ES6+)

  • async / await
  • Destructuring
  • Spread operator
  • Modules
  • Optional chaining
  • Nullish coalescing

8. JavaScript Ecosystem

Frameworks: React, Vue, Angular, Svelte

Backend: Node.js, Express, NestJS

Tools: npm, Vite, Webpack, Babel

9. Pros & Cons

Pros

  • Everywhere
  • Huge community
  • Fast development
  • One language, many platforms

Cons

  • Too flexible → bugs
  • Async misuse → callback hell
  • Weak typing (TypeScript fixes this)
